# Architecture Decision Records

Architecture Decision Records (ADRs) document the rationale for significant architectural decisions.

ADR filenames use `NNNN-kurzer-titel.md`.

Allowed statuses are `Proposed`, `Accepted`, `Superseded`, `Deprecated`, and `Rejected`. Coding Agents may create new ADRs only with status `Proposed`; `Accepted` and all later status changes require a human.
